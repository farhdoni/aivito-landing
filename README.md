# aivito-landing

MedSoft splash page for [aivito.uz](https://aivito.uz).

## About MedSoft
Экосистема заботы о здоровье: профилактика, лечение, реабилитация.
Платформа следующего поколения с ИИ-маршрутизацией, SOS-алгоритмом и цифровым двойником пациента.

## Tech
- Pure HTML/CSS/JS — zero dependencies
- Deployed via Coolify (self-hosted PaaS)
- SSL: Let's Encrypt (auto-renewed)
- Auto-deploy on push to `main`
